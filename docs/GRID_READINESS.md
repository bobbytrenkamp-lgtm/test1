## Disclaimer

County-level screening score only. It ranks counties by mapped public grid infrastructure and interconnection-queue activity on the axes listed -- it is not a statement about available interconnection capacity, utility willingness to serve, or transmission headroom, none of which are published in any free national dataset. A high score means real substations and/or active interconnection requests were found in this county's public data, nothing more. Every component and its rule is shown so the number can be checked rather than trusted.
